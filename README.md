# Dhaka-Tesla-Pool

> **Share a seat. Split the fare. Survive Dhaka traffic.**

A ride-pooling platform designed to optimize seat capacity, lower commute costs, and reduce congestion in Dhaka through smart pooling for Teslas.

## Project Structure & Documentation

This repository contains the frontend client application and comprehensive project documentation:

- **[Docs/PRD.md](Docs/PRD.md)**: Product Requirements Document, core business logic, matching rules, fare calculations, and system architecture.
- **[Docs/specs/](Docs/specs/)**: Detailed feature design specifications (e.g. SSLCommerz wallet top-up).
- **[Docs/plans/](Docs/plans/)**: Step-by-step implementation plans.
